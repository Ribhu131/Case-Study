## 📌 Project Overview

This project investigates India's startup ecosystem using exploratory data analysis (EDA) and Python-based data visualization.

The analysis explores startup funding patterns, investment trends, industry distribution, geographic preferences, and investor activity to better understand the factors shaping startup financing.

## 🎯 Project Objectives

- Analyze startup funding trends over time.
- Identify industries attracting investment.
- Explore geographic patterns in startup funding.
- Examine investor activity and funding preferences.
- Visualize findings using charts and graphs.
- Develop practical data analysis and visualization skills.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Programming language |
| Pandas | Data manipulation and analysis |
| NumPy | Numerical operations |
| Matplotlib | Data visualization |
| Seaborn | Statistical visualization |
| Jupyter Notebook | Interactive analysis |

## 📊 Analysis Highlights

- Startup funding trends over time
- Funding distribution across industries
- Geographic distribution of startup investments
- Investor participation and activity
- Funding types and investment patterns

## 🚀 Getting Started

### Prerequisites

- Python 3.8 or later
- Jupyter Notebook
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/Ribhu131/Case-Study.git
```

Navigate to the project directory:

```bash
cd Case-Study
```

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open `Startup_Analysis.ipynb` and run the cells sequentially.
